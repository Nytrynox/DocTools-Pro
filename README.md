# DocTools Pro

Document processing toolkit for PDF manipulation, format conversion, batch operations, and document merging.

## Features

- PDF merge, split, and page extraction
- Format conversion between PDF, DOCX, and images
- Batch processing for bulk document operations
- Watermark and header/footer insertion
- Document metadata editing

## Tech Stack

Dart, Flutter, PDF Libraries

## Getting Started

### Prerequisites

- Flutter SDK
- flutter

### Installation

```bash
git clone https://github.com/karthik-idikuda/DocTools-Pro.git
cd DocTools-Pro
flutter pub get
```

### Usage

```bash
flutter run
```
